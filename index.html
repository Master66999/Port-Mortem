📜 Non-Trivial Architectural Divergence (DECISIONS.md)

1. Strong Static Typing (`i32`)

Rust enforces strict compile-time types with i32 for valid ranges (0..4999) without dynamic dynamic overhead or object allocations.

2. Result Enums

Explicit zero-cost error propagation via custom enums (OutOfRange, InvalidRomanNumeral) instead of raising dynamic exceptions.

3. Lazy Regex (`LazyLock`)

Thread-safe lazy static compilation of Roman numeral DFA regex graphs on first use, eliminating initialization overhead.

4. Zero Handling ('N')

Preserves 100% parity with Python roman version 3.x+ for representing zero as 'N' via from_roman_with_special_case.

5. Clap v4 CLI Interface

Derive-macro UNIX CLI syntax with -r/--reverse flags and automatic standard OS exit status codes.
